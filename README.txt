Sa3y Portfolio — Arabic / English

1) Open index.html in a browser to preview the site.
2) To publish for free with GitHub Pages:
   - Create a public repository named sa3y-portfolio on GitHub.
   - Upload the CONTENTS of this folder (index.html, .nojekyll, README.txt) to the repository root.
   - Open Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Choose branch main and folder /(root), then Save.
   - After deployment, GitHub shows the public website URL in the Pages section.

Before publishing, replace the sample project cards with real projects and add your email, WhatsApp and LinkedIn links. Do not upload private or confidential business data.
